GoMLInstaller source

Install GoML.

A statically typed language with Rust-like syntax that compiles to Go.

For Linux amd64 and macOS arm64. Install Go 1.26 or newer first, then run:

curl -fsSL https://gomlang.github.io/install/install.sh | sh

The installer downloads the latest release, verifies its checksum, and initializes the toolchain. It requires curl, tar, and sha256sum or shasum.

Start a project

Add the PATH command printed by the installer to your shell configuration. For the default installation:

export PATH="${GOML_HOME:-$HOME/.goml}/bin:$PATH"
goml new hello
cd hello
goml run

Choose a version or directory

curl -fsSL https://gomlang.github.io/install/install.sh | sh -s -- \
  --version X.Y.Z --prefix "$HOME/tools/goml"

Replace X.Y.Z with a published version. Run the installer again to upgrade. Your dependency cache is preserved.
